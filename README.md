## 01. Overview

**Ness Splicerr** is a creative audio slicing, chopping, and glitch processing VST plugin designed for music producers, beatmakers, and sound designers.

Developed by **Ness Tangsang**, this release delivers a creative environment for precision transient detection, rhythmic rearrangement, and real time audio manipulation directly inside your digital audio workstation.

## 02. Key Features

### Real Time Audio Slicing

Automatically detects audio transients or synchronizes slicing to your DAW tempo grid for precise beat chopping and rhythmic rearrangement.

### Creative Glitch and Stutter Engine

Transform individual audio slices using reverse playback, pitch shifting, tape stop effects, and micro loop manipulation.

### Intuitive User Interface

A clean, responsive interface designed for efficient workflow, hands on control, and creative sound design.

### Full DAW Automation

Control and automate supported slicing parameters and effect controls directly through your host DAW automation system.

## 03. Installation Instructions

**Windows 64 Bit**

1. Download `ness_splicerr_X64_setup.exe`.
2. Double click the installer to launch the setup wizard.
3. Follow the installation instructions.
4. Install the VST3 plugin into the default directory:

   `C:\Program Files\Common Files\VST3`

5. Launch your preferred DAW.
6. Rescan the VST3 plugin directory.
7. Locate and load **Ness Splicerr** in your plugin browser.
